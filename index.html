Connect Nightly Log

One-time setup on this phone. The app saves to your private GitHub repo, so it needs a GitHub token that can only touch that one repo.

  1. Open GitHub → New fine-grained token (sign in if asked).
  2. Token name: Nightly Log app. Expiration: 1 year (or longer).
  3. Repository access: Only select repositories → pick nightly-log-data.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Tap Generate token, copy it, and paste it below.

The token stays on this phone and is only sent to GitHub.
